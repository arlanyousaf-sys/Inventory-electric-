# Electrical Equipments — Tehzeeb G9 

This is a standalone Progressive Web App (PWA).

## GitHub Pages
Upload all files/folders in this directory to a GitHub repository and enable **Settings → Pages → Deploy from branch → main → / (root)**.

Open the resulting HTTPS GitHub Pages URL on Android Chrome. The browser can then offer **Install app / Add to Home screen**.

### Files
- `index.html` — main application
- `manifest.json` — PWA manifest
- `sw.js` — offline service worker
- `icons/` — PWA icons
